# BillCutter – AI Powered Smart Shopping Recommendation System

## Project Overview
BillCutter is an AI-powered smart shopping recommendation system that identifies products from uploaded images using the MobileNetV2 deep learning model and compares prices across multiple e-commerce platforms to recommend the best available deal.

## Features
- Visual AI Product Recognition
- Manual Product Search
- Multi-Platform Price Comparison
- Best Deal Recommendation
- Interactive Price Comparison Charts
- User-Friendly Streamlit Interface

## Technologies Used
- Python
- Streamlit
- PyTorch
- TorchVision
- MobileNetV2
- Pandas
- Plotly
- Pillow
- Microsoft Excel
